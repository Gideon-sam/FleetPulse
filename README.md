## Overview

**FleetPulse** is a connected-vehicle data platform designed for live fleet tracking, vehicle health monitoring, and AI-driven predictive insights.

---

## Core Features

• Built a connected-vehicle data platform that streams simulated GPS, speed and diagnostic telemetry through Apache Kafka for live fleet tracking and vehicle health monitoring.
• Designed event-driven Spring Boot microservices and REST APIs for telemetry ingestion, processing and fleet status queries.
• Analyzed historical telemetry and trained a Python ML model to flag abnormal vehicle behavior and predict likely maintenance issues, turning raw data into fleet-health insights.
• Used PostgreSQL for persistence and Redis caching for low-latency vehicle status lookups; load-tested concurrent workloads with JMeter; containerized with Docker.
